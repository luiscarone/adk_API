## 🔍 Example Usage

### New v2.1 Features

#### Fast Class Lookup with Fuzzy Search
```python
# Exact match
find_class("BRepBody")

# With typo - gets suggestions
find_class("BrepBdy")  # Suggests: BRepBody, BRepEdge, etc.
```

#### Method Lookup Across All Classes
```python
# Find which classes have this method
find_method("createExtrude")
# Returns: ExtrudeFeatures, Component, etc.
```

#### Class Hierarchy Visualization
```python
# See inheritance tree
get_class_hierarchy("Sketch")
# Shows: parent classes and child classes
```

#### Instant Class Listing
```python
# List all classes instantly
list_all_classes()

# Filter by module
list_all_classes("fusion")
```
