┌───────────────────────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                                             │
└───────────────────────────────────────────────────────────────────────────────┘

PROBLEM: Scripts won't execute
SOLUTION: chmod +x install.sh start.sh test_installation.sh

PROBLEM: Python version too old
SOLUTION: Install Python 3.8+ first

PROBLEM: venv not created
SOLUTION: Install python3-venv package
          sudo apt install python3-venv (Ubuntu/Debian)

PROBLEM: MCP packages fail to install
SOLUTION: Check internet connection
          Try: pip install fastmcp mcp --verbose

PROBLEM: Server won't start
SOLUTION: Run ./test_installation.sh to diagnose
          Check output for specific error

PROBLEM: Client can't find server
SOLUTION: Verify paths in mcp config match your system
          Check PATHS_REFERENCE.txt for correct paths
